# About this dashboard

Generated by [code-diligence](https://github.com/AeyeOps/aeo-diligence-marketplace).

## Methodology

The dashboard is generated by the `code-diligence` Claude Code plugin, which wraps six OSS tools (repowise, git-truck, git-fame, code-maat, hercules, git-of-theseus) plus a git-log walker plus optional GitHub API platform adapters.

## Confidence levels

- **High** — all expected data sources for this axis populated; cross-checks between tools agree
- **Medium** — most sources populated, or some tool failures isolated to specific repos
- **Low** — substantial sources missing or many repos failed; treat numbers as directional

## Curation

Three YAML files in `<curation_dir>` are the source of truth for analyst overrides:
- `identity-merges.yaml` — author identity merging
- `fte-classification.yaml` — FTE / contractor / bot classification
- `repo-classification.yaml` — repo class

Edit these files between ingest runs to override the heuristic; subsequent runs respect your edits.
