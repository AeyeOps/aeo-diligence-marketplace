# About this dashboard

Generated by [code-diligence](https://github.com/AeyeOps/aeo-diligence-marketplace).

## Methodology

The dashboard is generated by code-diligence, which runs six open-source tools (repowise, git-truck, git-fame, code-maat, hercules, git-of-theseus), a git-log walker and optional GitHub data collection.

## Confidence levels

- **High:** at least 80% of expected sources are present
- **Medium:** 40–79% of expected sources are present
- **Low:** fewer than 40% of expected sources are present

A source is present when it has data. A GitHub source also counts when it was collected without a failure, because an empty result there means the feature is not used. Completeness does not measure repository coverage, accuracy, or agreement between tools. Health lists current collection failures.

## Curation

Three YAML files in `<curation_dir>` are the source of truth for analyst overrides:

- `identity-merges.yaml` — author identity merging
- `fte-classification.yaml` — FTE / contractor / bot classification
- `repo-classification.yaml` — repo class

Edit these files between ingest runs to override the heuristic; subsequent runs respect your edits.

## Tool versions

```js
import { query } from "./data/warehouse.js";
const versions = await query(`SELECT target_id, name, tooling_versions FROM targets ORDER BY name`);
for (const target of versions) {
  display(html`<h3>${target.name}</h3>`);
  if (target.tooling_versions === null) display(html`<p>Tool versions have not been recorded.</p>`);
  else display(Inputs.table(Object.entries(JSON.parse(target.tooling_versions)).map(([tool, version]) => ({tool, version}))));
}
```
